# Web UI design system

The source of truth for Quevo's visual tokens, components, status colors, motion, and accessibility rules is the [black-and-white visual system](design/visual-system.md). The landing page uses a queue-specific interactive preview and product details to add personality while keeping the shared interface neutral and practical.

The web application keeps its React/TanStack architecture, Tailwind CSS v4, shadcn/ui controls, Geist Sans and Geist Mono fonts, Motion for React, and Lucide icons. Add page composition through shared semantic tokens and the existing component patterns; avoid introducing a second visual or component system.

Customer queue behavior is documented in the [customer ticket flow](customer-ticket-flow.md), operator state and actions in the [operator dashboard](operator-dashboard.md), and landing-page structure in the [landing page guide](landing-page.md).
